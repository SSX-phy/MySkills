# Physical Review B (PRB) — Cover Letter Reference

Source: https://manusights.com/blog/physical-review-b-submission-guide
Primary APS page: https://journals.aps.org/prb/authors
## Mapping
- prb, physical review b → `prb`
---

## Status

Cover letter is **optional**. Include it when:
- The scope fit is borderline (e.g., the topic spans PRB and another journal)
- The article type is "PRB Letters" (requires explicit justification)
- There are CJK author names that need flagging

For routine submissions where scope is clear, a cover letter is not expected.

---

## Structure

Use the standard 4-paragraph formalism.

### Paragraph  2 — What Was Done, Main Findings, Significance

For computational work: briefly name the key convergence tests or validation benchmarks used.
PRB reviewers consistently expect computational reproducibility — flagging it in Paragraph 2 signals
awareness of this expectation.


### Paragraph  4 — Corresponding Author and Requirements

Include:
1. Correspondence line.
2. Note any **joint submissions** and **prior Physical Review submission history** if applicable.
3. **CJK author names**: If any author name contains Chinese, Japanese, or Korean characters,
   add the following:
   > "Please note that [author name(s)] contain [Chinese/Japanese/Korean] characters.
   > We have included the romanised forms in the manuscript."

---

## Do's and Don'ts

**Do:**
- Keep the letter brief — PRB editors do not require it, so respect their time.
- Make the APS fit argument specific: name the subfield community within PRB.

**Don't:**
- Generate a 100-word justification paragraph — that is PRL-only, not required for PRB.
- Submit a cover letter for a clearly in-scope regular article unless there is something
  specific to communicate.
